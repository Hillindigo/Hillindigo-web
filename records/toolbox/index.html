选择工具的标准

一个工具进入长期工作流之前，需要回答三个问题：

  1. 它解决的是高频问题吗？
  2. 它能否被脚本或配置复现？
  3. 停止维护后是否容易迁移？

工具类别

  • 编辑与搜索；
  • Git 与版本管理；
  • HTTP 和网络诊断；
  • 截图与视觉验证；
  • 文档和图表；
  • 自动化构建。

定期清理

工具列表也需要维护。长期没有使用、功能高度重叠或依赖不稳定服务的工具，应当移出主要工作流，避免选择成本不断增加。
