AstroMarkdown内容系统

为什么要把内容独立出来

当页面中的标题、摘要和正文全部写在组件里时，每增加一篇内容都需要修改页面代码。它适合制作展示原型，却不适合持续写作。

内容集合把文章变成独立的 Markdown 文件，页面只负责读取、排序和展示。这样可以保持三个边界清晰：

  • Markdown 保存内容；
  • Astro 组件决定表现；
  • Git 记录每一次变化。

结构化字段

每篇记录至少需要标题、摘要、发布日期和标签。构建阶段会检查这些字段，因此错误内容不会悄悄进入正式网站。

title: "一篇记录"
description: "一句清楚的摘要"
publishedAt: 2026-07-18
tags: [Astro, 内容系统]

静态生成

文章详情、标签和分页都在构建时生成 HTML。部署完成后，GitHub Pages 只需要分发静态文件，不需要数据库和运行时服务器。

内容可以不断变化，交付形态仍然保持简单、稳定和可迁移。

下一步

前台结构稳定后，再把网页编辑器接到同一批 Markdown 文件上。编辑器提交 GitHub，Actions 自动构建，页面继续保持纯静态。
