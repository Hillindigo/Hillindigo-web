GitHub Pages 项目路径的完整处理方式

自定义域名和项目仓库拥有不同的基础路径，所有链接与静态资源都需要遵守同一条路径规则。

两种部署地址

GitHub Pages 常见的部署方式有两种：自定义域名部署在根路径，项目仓库部署在仓库名称对应的子路径。

https://hillindigo.ccwu.cc/
https://username.github.io/repository/

页面如果直接写死 /records/，在第二种地址下就会跳回域名根目录。正确做法是统一使用 Astro 提供的基础路径。

内部链接

const base = import.meta.env.BASE_URL;

<a href={`${base}records/`}>记录</a>

图片、样式资源和分页链接也必须遵守相同规则。

静态目录

开启尾部斜杠后，/records/page/2/ 会生成对应目录中的 index.html。这样直接刷新子页面时，GitHub Pages 可以正确找到文件。

构建检查

发布前需要分别使用根路径和模拟仓库子路径构建，检查首页、文章页、标签页、分页和图片地址。
